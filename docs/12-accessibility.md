# Accessibility

Target WCAG 2.2 AA principles.

## Requirements

- semantic HTML
- logical heading hierarchy
- keyboard navigation
- visible focus states
- descriptive form labels
- accessible error messages
- adequate colour contrast
- alt text for meaningful images
- empty alt for decorative images
- buttons must have clear accessible names
- no interaction should depend solely on hover
- support reduced motion

## Language

Use lang="en-GB" for English pages.

Future translated pages must use the appropriate language attribute and hreflang strategy.

## Mobile

Tap targets should be comfortably usable.

Phone and WhatsApp actions should not be hidden behind tiny icons.
