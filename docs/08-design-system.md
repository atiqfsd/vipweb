# Design System

## Design objective

The design should look like a mature local technology business, not a generic AI-generated startup.

## Layout

Use generous whitespace but avoid huge empty hero sections.

Desktop:
- max content width around 1200–1280px
- clear grid system
- 12-column layout where useful

Mobile:
- single-column first
- sticky/collapsible contact actions where appropriate
- large readable tap targets

## Colour

Working palette:
- Deep Navy #071A2B
- Navy #0D2940
- Technology Blue #087EA4
- Cyan #18A9C8
- Off White #F5F7F8
- Slate #334155
- Muted #64748B
- Border #DCE4E8

Treat these as provisional until final brand assets are supplied.

## Components

Create reusable components:
- Header
- Mobile navigation
- Footer
- CTA button
- Service card
- Service category block
- Breadcrumbs
- Testimonial card
- Review summary
- FAQ accordion
- Contact CTA
- Contact form
- Location block
- Language switcher placeholder
- Resource card
- Career vacancy card

Do not create a component for every one-off visual.

## Cards

Cards should be restrained.

Use borders, whitespace and hierarchy before shadows.

Avoid the common AI pattern of:
icon + gradient + rounded card + huge heading + tiny paragraph.

## Imagery

Prefer large editorial-style photography and contextual images.

Images should support the message, not merely decorate it.

## Motion

Subtle only:
- small hover transitions
- menu transitions
- reveal animations where genuinely useful

Respect prefers-reduced-motion.

No perpetual floating objects.

## Accessibility

Target WCAG 2.2 AA principles:
- keyboard navigation
- visible focus
- sufficient contrast
- semantic headings
- descriptive labels
- alt text
- accessible forms
- reduced-motion support

## Responsive design

Design mobile first.

The majority of application-assistance customers may arrive from phones, so:
- phone number should be easy to tap
- WhatsApp CTA should be prominent
- location should be obvious
- service categories should be scannable
- forms should be short
