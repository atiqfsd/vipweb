# Project Overview

## Goal

Create a premium, trustworthy, fast and SEO-focused website for VIP e-Services that accurately represents the two sides of the business:

### Digital & IT Solutions
Real services delivered by the company.

### Consultancy & Application Assistance
Practical help for customers completing applications for benefits, housing, employment, licences, identity/travel documents and related services.

## Success criteria

The finished website should:

- make the business understandable within seconds
- create trust without fake claims
- make services easy to find
- work exceptionally well on mobile
- target East London search intent
- have strong technical SEO
- provide clear phone/WhatsApp/contact CTAs
- support English, Urdu, Hindi and Punjabi in the architecture
- feel bespoke rather than template-generated
- load quickly
- use accessible semantic HTML
- be easy to maintain in Claude Code

## Recommended stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui only where useful
- MDX/content files for service and resource content
- next/image
- JSON-LD structured data
- Static/server-rendered pages wherever possible

Do not introduce a database unless a real business requirement appears.

## Design principle

Design for trust and clarity first. Technology should support the business rather than become the visual identity.
