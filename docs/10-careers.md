# Careers

## Page title

Work with VIP e-Services

## Current state

The client will add real job vacancies later.

Therefore the initial website must NOT invent vacancies, salaries or job descriptions.

## Page structure

1. Hero
2. About working at VIP e-Services
3. Areas of work
4. What we value
5. Future opportunities
6. Speculative application CTA
7. Contact

## Suggested areas

Only include areas the client confirms:
- Digital & IT
- Customer service
- Application assistance
- Digital marketing
- Administration

## Future vacancy component

Build a reusable vacancy component so real roles can later be added.

Fields:
- title
- location
- employment type
- summary
- responsibilities
- requirements
- application instructions

## Application

Initial v1 can use:
- email
- contact form
- CV upload only if a secure implementation is available

Do not create an insecure public file-upload endpoint.

## Tone

Professional, realistic and modest.

Avoid generic phrases such as “join our fast-paced innovative family” unless supported by actual company culture.
