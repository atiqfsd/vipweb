## Local SEO

Ensure consistent NAP:
Name: VIP e-Services
Address: 134B Barking Road, London, E6 3BD
Phone: 020 3685 7733

Use:
- LocalBusiness schema where appropriate
- Organization schema
- Service schema where appropriate
- BreadcrumbList
- FAQPage only when the page actually contains visible FAQs
- WebSite schema
- sameAs links once official profiles are supplied

Do not create fake review schema or rating markup.

## On-page SEO

Every indexable page needs:
- unique title
- unique meta description
- one clear H1
- logical H2/H3 hierarchy
- descriptive internal links
- optimised images
- useful body content
- relevant FAQ where helpful
- canonical URL

## Content strategy

Create a Resources section.

Content should answer real customer questions and link naturally to relevant services.

Do not publish generic AI articles at scale.

Every article should:
- solve a specific problem
- cite official sources when discussing government processes
- explain VIP e-Services' role clearly
- avoid pretending to be official guidance
- have an author/review process once the owner confirms who is responsible

## Technical SEO

Implement:
- XML sitemap
- robots.txt
- canonical URLs
- Open Graph metadata
- Twitter/X metadata if relevant
- semantic HTML
- image alt text
- clean URLs
- redirects for old URLs
- 404 page
- fast Core Web Vitals
- no unnecessary client-side JavaScript

## Old site migration

Existing URLs include:
- /
- /About-us/
- /Services/
- /Contacts/

Preserve or redirect these paths appropriately during launch.

Do not break indexed URLs.

## Multilingual SEO

Build the application so additional languages can be introduced cleanly.

Do not machine-translate the full site and publish without human review.

Potential future routes:
 /ur/
 /hi/
 /pa/

Final language URL strategy should be decided before implementation.
